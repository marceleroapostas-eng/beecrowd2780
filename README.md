# Beecrowd 2780 - Basquete de Robôs



## Descrição



Este programa resolve o problema 2780 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém um valor inteiro D, representando a distância do robô até o início da quadra, em centímetros.



## Saída



O programa apresenta a quantidade de pontos correspondente à distância informada.
